# Sajeebarath Suntharalingam | Cyber Security Portfolio

A dependency-free Node.js portfolio featuring academic projects, evidence, education and a downloadable CV.

## Run locally

With Node.js 20 or later, open a terminal in this folder and run `npm start`. Open http://localhost:3000. The server renders the page from the source files on each request.

## Edit and publish

Edit the content in `src/page.html`, the design in `src/style.css`, and theme behaviour in `src/theme.js`. Photos, evidence and the CV live in `assets/`.

Run `npm run build` after editing. It refreshes the root `index.html` for GitHub Pages and produces a self-contained `dist/` for other static hosts. Keep the generated root page and `assets/` together. The included root page is already built and opens offline.

For the existing GitHub Pages repository, upload the extracted project contents to its root and commit. Keep Pages on main and /(root).
